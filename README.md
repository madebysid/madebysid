### What I build

- **Product engine:** scrapes competitors, then lists and prices about 1,000 products a week.
- **Reporting:** weekly and monthly business review decks built automatically from the P&L.
- **Refund reconciliation:** recovers about $4k per store per month.
- **CRM and AI agents:** workflows for acquisition, sales, operations and content, using tool calling and MCP.

That work is private. What I publish here are small, generic open-source tools based on the same problems.
